# English Lab

Página **gratis**, sin servidor. Pulsa las palabras para oírlas. A1 → B2. Meta: B1.

Abre [index.html](./index.html) en Chrome o Edge, o usa GitHub Pages.

Progreso: queda en tu navegador (este aparato). No se sube nada a internet.

## Publicar (GitHub Pages)

Este repo **es** el sitio: la raíz es la página.

1. **Settings → Pages → Source: GitHub Actions**.
2. Cada `push` a `main` publica sola. También puedes correr el workflow a mano.
3. URL: `https://<usuario>.github.io/englishlab/`
